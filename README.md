# Taskbar Drawer (Windows 11 快捷抽屉)

专为 Windows 11 打造的轻量级系统托盘快捷抽屉，专门解决 `.bat`、`.cmd`、`.ps1`、绿色便携工具等无法直接固定到任务栏的痛点。

---

## ✨ 核心特性

1. **纯悬浮托盘抽屉（不占任务栏按键）**：
   - 彻底移除了主任务栏的图标标签，常驻在屏幕右下角系统托盘（`^` 区域）；
   - **左键单击托盘图标**：智能唤醒与收起抽屉（Toggle）；
   - **右键单击托盘图标**：呼出原生上下文菜单（打开抽屉、打开快捷目录、退出程序）。

2. **多模式快捷录入**：
   - **外部拖拽**：直接从桌面或文件资源管理器把 `.bat` / `.cmd` / `.exe` / `.lnk` 拖入抽屉窗口，自动添加并智能提取高分辨率程序图标；
   - **目录直通**：直接将脚本放入软件同级的 `shortcuts/` 文件夹，自动侦测同步；
   - **手动添加**：点击顶部 `➕ 添加` 按钮，通过系统原生文件选择器挑选。

3. **网格与列表布局一键切换**：
   - 支持 **⊞ 网格模式**（大图标卡片）与 **☰ 列表模式**（高密度清单），点击右上角按钮即可切换，布局自动持久化。

4. **图标自由拖拽排序**：
   - 鼠标按住任意卡片拖拽，其他卡片高亮提示放置位置，松手即刻完成位置调整并自动保存。

5. **右键高级执行选项**：
   - 右键任意卡片可选择：
     - `🛡️ 以管理员身份运行`
     - `🤫 静默运行（彻底隐藏 CMD 黑框）`
     - `📂 在资源管理器中定位`
     - `🗑️ 移除快捷方式`

6. **Windows 11 原生美学与极速体验**：
   - 自动检测任务栏位置与屏幕分辨率，精准停靠在右下角系统托盘正上方；
   - 适配 Win11 DWM 原生圆角微亚克力质感，内嵌系统微软雅黑（Microsoft YaHei）字体；
   - 支持 **失焦后自动关闭** 与 **运行后自动关闭**，支持 `Esc` 键及 `✕` 瞬间隐藏；
   - 隐藏待命期间 CPU 占用 **0.0%**，内存开销极低。

## 📁 目录结构

```
TaskbarDrawer/
├── .cargo/config.toml       # Cargo 加速配置
├── Cargo.toml               # Rust 依赖与 release LTO 优化配置
├── shortcuts.json           # 快捷方式与设置持久化配置
├── shortcuts/               # 本地快捷方式脚本目录
└── src/
    ├── main.rs              # 入口、Win11 工具窗口样式初始化
    ├── app.rs               # egui 核心交互界面与焦点/拖拽/失焦逻辑
    ├── tray_manager.rs      # Windows 系统托盘图标、事件与防抖
    ├── win_utils.rs         # Win32 坐标吸附计算与 DWM 圆角属性
    ├── launcher.rs          # 脚本提权运行与静默执行
    ├── icon_extractor.rs    # 原生 Win32 Shell 图标提取与解析
    ├── font_utils.rs        # 系统微软雅黑中文字体加载
    ├── config.rs            # 配置加载、扫描与保存
    └── logger.rs            # 运行时日志输出
```

## 🛠️ 构建与运行

### 环境要求
- Windows 10 / 11
- Rust 1.80+ 工具链

### 编译构建
```bash
# 调试运行
cargo run

# 构建极致优化生产版本 (LTO + Strip + Panic Abort)
cargo build --release
```

编译出的独立可执行程序位于 `target/release/taskbar-drawer.exe`（单文件约 3.6MB，无外部运行时依赖）。
